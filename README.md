# 🎤 Brofessor Beats — pakiet startowy kanału

Kompletny zestaw materiałów do uruchomienia kanału YouTube w niszy hip-hopowej,
wzorowanego na formule kanału [Brofessor Stein](https://www.youtube.com/@BrofessorStein)
(336 tys. subów / ~70 mln wyświetleń w 2 lata, format "Every X Explained By a German").

## Formuła w jednym zdaniu

> Jeden sztywny, powtarzalny format listowy ("Every X in Hip-Hop Explained")
> z wyrazistą personą, publikowany 2× w tygodniu bez wyjątku przez minimum 6 miesięcy.

## Zawartość pakietu

| Katalog | Co zawiera |
|---|---|
| [`01-brand/`](01-brand/) | Nazwa, persona, opis kanału, trailer, identyfikacja wizualna, spec thumbnaili |
| [`02-content/`](02-content/) | 50 tematów odcinków, kalendarz na 12 tygodni, szablon scenariusza, pełny scenariusz odcinka 1, strategia Shorts |
| [`03-produkcja/`](03-produkcja/) | Sprzęt i narzędzia (budżet start / pro), workflow produkcji krok po kroku, checklisty |
| [`04-seo/`](04-seo/) | Szablony tytułów, opisów i tagów, strategia metadanych |
| [`05-prawo/`](05-prawo/) | Fair use, Content ID, jak legalnie robić filmy o muzyce i nie stracić monetyzacji |
| [`06-monetyzacja/`](06-monetyzacja/) | Plan przychodów etapami: AdSense → sponsorzy → afiliacja → własne produkty |
| [`07-analityka/`](07-analityka/) | KPI, benchmarki, progi decyzyjne "skaluj / popraw / porzuć temat" |

## Od czego zacząć (pierwsze 7 dni)

1. **Dzień 1:** przeczytaj `01-brand/` i podejmij dwie decyzje: nazwa + język (rekomendacja: angielski, globalny hip-hop).
2. **Dzień 2:** załóż kanał, wgraj logo/banner wg specu z `01-brand/identyfikacja-wizualna.md`, ustaw opis z `01-brand/opis-kanalu.md`.
3. **Dzień 3–5:** nagraj odcinek 1 wg gotowego scenariusza `02-content/scenariusz-odcinek-1.md`.
4. **Dzień 6:** montaż wg `03-produkcja/workflow-produkcji.md`.
5. **Dzień 7:** publikacja z metadanymi z `04-seo/` + wytnij 3 Shortsy wg `02-content/strategia-shorts.md`.

Potem: kalendarz z `02-content/kalendarz-12-tygodni.md` i konsekwencja.
